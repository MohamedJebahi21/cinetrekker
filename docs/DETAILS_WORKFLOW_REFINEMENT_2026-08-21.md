# Media Details Workflow Refinement

The title-details page remains CineTrekker’s central decision and tracking surface. This refinement preserves every existing title action while making the cinematic backdrop, title, key metadata, and tracking controls easier to scan.

| Area | Refinement | Retained behavior |
| --- | --- | --- |
| Cinematic hero | Removed the decorative grain layer, reduced routine blur, and made the return control, poster, score, and metadata calmer. | Backdrop, responsive poster, title, tagline, rating, content rating, status, creators, networks, and title facts remain available. |
| Metadata | Replaced multiple hero pills with a concise inline primary-metadata line and simple genre text. | Movie/TV type, year, rating, status, certification, runtime, season/episode count, cast and provider data are unchanged. |
| Section navigation | Rebased the sticky section navigation on opaque product surfaces and compact selected-state feedback. | Overview, video, cast, episodes, recommendations, and reviews navigation remains unchanged. |
| Tracking controls | Replaced the blurred action container and exaggerated elevation with one quiet action panel and standard buttons. | Watchlist, watched status, episode management, follow updates, pinned favorites, trailer, sharing, optimistic updates, guest local persistence, and authentication-safe flows are unchanged. |

The refinement is visual and structural only. It does not alter TMDB requests, Supabase data, watch history, ratings, episodes, favorites, notifications, or any user preference.
